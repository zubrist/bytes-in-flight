## 📚 Roadmap Tracker

- [ ] **1. Overview of Data Communication and Networking**
  - [✅] Introduction: Data communications components, data representation, and direction of data flow (simplex, half-duplex, full-duplex).
  - [✅] Network Hardware: Physical structure (connection types, network topologies), and categories of networks (LAN, MAN, WAN).
  - [ ] Internet: Brief history, protocols, and standards.
  - [ ] Reference Models: OSI reference model, properties of all layers, TCP/IP reference model, and their comparative study.

- [ ] **2. Physical Layer**
  - [ ] Data & Signals: Analog and digital data/signals, periodic and non-periodic signals, composite signals, bandwidth, bit rate, and transmission of digital signals.
  - [ ] Transmission Impairments: Attenuation, distortion, and noise.
  - [ ] Data Rate Limits: Noiseless channel (Nyquist Data Rate), noisy channel (Shannon’s Capacity), and calculation of data rates using both limits.
  - [ ] Digital Transmission:
    - [ ] Digital-to-Digital Conversion: Line coding schemes (RZ, NRZ, Manchester, Differential Manchester), and block coding.
    - [ ] Analog-to-Digital Conversion: Sampling, Nyquist rate of sampling, Pulse Code Modulation (PCM), Delta Modulation (DM), Adaptive Delta Modulation (ADM), along with parallel and serial transmission.
  - [ ] Analog Transmission:
    - [ ] Digital-to-Analog Conversion: Amplitude Shift Keying (ASK), Frequency Shift Keying (FSK), Phase Shift Keying (PSK), and Quadrature Amplitude Modulation (QAM).
    - [ ] Analog-to-Analog Conversion: Amplitude Modulation (AM), Frequency Modulation (FM), and Phase Modulation (qualitative study).

- [ ] **3. Bandwidth Utilization Techniques**
  - [ ] Multiplexing: Frequency Division Multiplexing (FDM), Synchronous & Statistical Time Division Multiplexing (TDM), and Wavelength Division Multiplexing (WDM).

- [ ] **4. Transmission Media**
  - [ ] Guided Media: Twisted-pair cable, coaxial cable, and fiber optics.
  - [ ] Unguided Media: Radio waves, microwaves, infrared, antennas, and communication satellites (qualitative study).

- [ ] **5. Switching and Telephone Networks**
  - [ ] Switching Mechanisms: Circuit-switched networks, packet-switched networks, and virtual circuit switches.
  - [ ] Access Networks: Major components of telephone networks, dial-up modems, DSL and ADSL modems, and cable TV for data transfer (qualitative study).

- [ ] **6. Data Link Layer**
  - [ ] Error Control & Framing: Types of errors, framing (character and bit stuffing), error detection & correction methods, linear and cyclic codes, and checksums.
  - [ ] Protocols & Addressing: Stop-and-Wait ARQ, Go-Back-N ARQ, Selective Repeat ARQ, HDLC (qualitative study), and physical addressing (MAC address structure and format).

- [ ] **7. Medium Access Sublayer**
  - [ ] Access Control: Point-to-Point Protocol (PPP), Token Ring (reservation, polling), and multiple access protocols (Pure & Slotted ALOHA, CSMA, CSMA/CD, CSMA/CA).
  - [ ] Channelization & LAN Standards: FDMA, TDMA, CDMA (qualitative), wired and wireless LAN standards, Fast Ethernet, IEEE 802.11, and Bluetooth.

- [ ] **8. Network Layer**
  - [ ] Devices & Internetworking: Repeaters, hubs, bridges, switches, routers, and gateways.
  - [ ] Addressing & Routing: IP addressing, subnetting, and routing techniques (static vs. dynamic routing).
  - [ ] Protocols: RARP, ARP, IP, and ICMP.

- [ ] **9. Transport Layer**
  - [ ] Process-to-Process Delivery: User Datagram Protocol (UDP) and Transmission Control Protocol (TCP).

- [ ] **10. Application Layer**
  - [ ] Protocols & Services: Introduction to DNS, remote logging, File Transfer Protocol (FTP), electronic mail, WWW, and HTTP.
